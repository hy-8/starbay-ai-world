# 星湾街区 · UE5 原生试玩 v0.2.0

这是虚构的星湾街区，当前是原生第三人称探索基础版。

## 开始

解压完整文件夹，双击 Windows/StarbayUE5.exe；不要只移动 EXE，旁边的 Engine 和 StarbayUE5 文件夹也是运行必需文件。无需浏览器、Blender、Python 或 UE 编辑器。

WASD 移动，鼠标转动镜头，空格跳跃，Alt+F4 退出。本版暂未制作开始菜单、地图界面或存档。

先探索广场，再绕行至商场入口、夜市与风栖茶庭。部分路线仅完成稀疏碰撞检查，尚未通过全部角色步行验收。门洞保持开放，自动门交互尚未实现。

## 本次已完成

- UE5.6.1 中的街区、商场陈设和茶庭场景。
- 官方 Third Person 角色、相机、原生 CharacterMovement 移动与跳跃。
- Lumen、DX12 SM6，以及适合当前合并模型的常规阴影。
- 茶庭叶片双面透光、石材/木材 PBR 与灯串发光。

当前角色是 Epic 官方模板人物，未制作成最终都市角色。模型、灯光和游戏内容仍属于早期开发，尚未达到大型写实游戏的完成度。

## AI 与后续开发

本地 Qwen 对话、NPC 日程与带路、昼夜、任务和存档仍在浏览器原型中；这个 UE5 试玩包尚未包含这些系统。

后续优先：拆分大场景并优化碰撞/Nanite；制作都市角色和动画；接入原生导航与行为状态机；再迁移本地 Qwen 的对话和受限高层意图。模型不会直接控制每帧骨骼动作。

## 运行要求与验证范围

建议 Windows 11、支持 DX12 SM6 的独立显卡；本次在 RTX 5060 Laptop 8GB / 16GB 内存机器验证。尚未建立最低配置或稳定帧率承诺，首轮启动可能编译管线并产生短时卡顿。

本版为 Development 预发布：不含联网玩法；无需为单人探索开放防火墙网络访问。不同电脑可能需要微软 Visual C++ 运行库，尚未完成干净系统兼容性测试。

地图采样和局部 PIE 移动/跳跃有自动化证据，完整街区通行、所有键位、长期稳定性仍需继续验收。
