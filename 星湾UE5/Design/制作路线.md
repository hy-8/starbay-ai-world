# 从街区原型到独立游戏

目标：虚构都市生活与探索。借鉴《荒野大镖客 2》的环境叙事、动作连贯性、世界对玩家的回应和昼夜生活节奏，制作自己的场景、角色与故事。不是复制其世界、角色、美术资源或承诺同等 AAA 规模。

## 第一阶段：可探索场景切片

先做入口—夜市—茶庭—公园—商场这一条完整步行路线。每处需要明确的视觉地标、近景细节、照明与停留理由。新增茶庭用石铺地、桌上书杯、旧木、植物和暖灯表现邻里活动；喷泉目前是静态水池，水流特效未实现。

迁移后首先验证米/厘米、轴向、地面高度与门洞；使用官方 Third Person 模板建立真实 Character、胶囊碰撞、移动组件、弹簧臂相机与动画蓝图。素材替换和场景美术在这条稳定的可玩路线之上迭代。

验收：能独立从入口走到每个区域、不卡门、不穿墙、不悬空；第三人称角色走跑停转正常；可打包 Windows 开发版并在编辑器关闭后运行。

## 第二阶段：写实材质与环境

- 统一真实尺寸和 PBR 材质。优先替换地面、木构件、建筑底层近景，按相机距离设置纹理密度。
- 从“有很多物件”转向“有使用痕迹”：雨痕、磨损边缘、店铺陈列变化、告示、座椅旁的生活物件。污渍和细节不能遮挡路线。
- 新树冠已拆成独立叶片；在 UE 中进一步配置双面植被材质、次表面透光和受控顶点风动。此轮未完成风动。
- 先做晴日、黄昏、夜晚三套可复现照明，再衔接连续昼夜；雨天需要材质湿润、声音、粒子和室内遮挡一起实现，不能仅加一层雨点。
- 保留截图基准机位，对照画面和帧时间，逐步替换程序化占位模型。现有资产仍有明显风格化特征，不等于完成写实美术。

## 第三阶段：NPC 真正生活起来

分工：本地 Qwen 生成对话和高层意图 → 服务校验 JSON 与目的地 → UE 的 StateTree/行为树安排状态 → NavMesh 与 CharacterMovement 执行 → 动画蓝图、动作混合和 IK 呈现。

旧人物的分段关节与 JS 步态不能直接当作 UE 骨骼动画使用。先用合法来源的标准骨骼角色验证移动与交互，再制作男女老少四类原创角色并做骨骼兼容、重定向、身高补偿和停转过渡。

居民日程包含逛街、工作、休息、聊天和返家；玩家靠近时要让路、朝向与应答，带路要等待玩家。语言模型不逐帧控制身体，不直接操作任意 UObject，不直接执行生成代码。

AI 请求采用异步 HTTP、角色级冷却、有限并发、取消/超时、受控记忆和可见的离线降级。使用本机 `127.0.0.1` Ollama；模型端失败不能阻塞帧循环。模型仅决定允许目的地与动作 ID，所有环境状态变更由白名单规则实施。

## 第四阶段：游戏循环与交付

将浏览器版任务和存档迁移为 UE 数据资产与 SaveGame；加入可观察的任务结果、小型环境事件、探索日志。先迁移现有规则任务，再研究可校验的 AI 任务提案。上传任意场景自动生成世界继续作为独立的未来研发目标。

每一轮交付真实可运行版本、工程、操作说明和相关测试，不用概念封面代替游戏画面。用户已经要求后续修改同步 GitHub，大型版本更新 Release。

## 这台机器的起步预算

已检测：RTX 5060 Laptop，约 8GB 显存，约 16GB 内存。先用 1080p、中等画质、软件 Lumen 和受控动态灯光测试；不开编辑器调试符号与不需要的平台包。不要同时把多个大型模型、Blender 渲染、UE 编译和高内存应用压在一起。

目标预算是开发方向，尚非实测结果：稳定 30 fps 起步，再争取 60 fps；重点看帧时间、显存、阴影、材质复杂度与纹理驻留。暂时采用小关卡，不为很小的区域增加不必要的 World Partition 和庞大系统。后续是否提高预算，以实际引擎测试为依据。
