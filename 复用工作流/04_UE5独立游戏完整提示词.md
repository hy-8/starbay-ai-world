# UE5 独立游戏续作提示词（当前优先路线）

请继续制作星湾虚构世界的 **Unreal Engine 5 Windows 独立游戏**。先读取根目录 AGENTS.md、`星湾UE5/README.md` 和 `星湾UE5/Design/制作路线.md`，核对实际工程、安装状态与验证报告，保护所有手工编辑。

用户选择写实画质与长期制作路线，不再以浏览器作为主要交付平台。借鉴《荒野大镖客 2》的世界细节、环境叙事、动作和生活节奏，保持原创都市设定，不复制其角色、地图和素材，不承诺立即达到 AAA 体量。

优先完成一个稳定的第三人称场景切片：入口、夜市、茶庭、公园、商场互通。复用现有 Blender 几何；运行资产导出与验证流程，在 UE 中检查一米标尺、轴向、地面、碰撞与门口。使用合法的官方 Third Person 模板验证角色移动和动画；编辑器飞行视角不算可玩第三人称版本。

资产建设使用原创模型或有明确授权的素材，并记录来源。推进 PBR 地面与木材、建筑近景、植被透光与风动、昼夜、声音和环境细节；以实机帧率与显存为依据选择 Lumen、阴影和纹理设置。当前制作机约 16GB 内存、8GB 显存，先做小区域并控制资源预算。

本地 AI 使用 Ollama/Qwen，负责语言与受控高层意图；UE 行为树/StateTree、NavMesh、CharacterMovement、动画蓝图和 IK 执行实际行为。请求异步、限并发、可取消，校验目的地与动作白名单，模型失败时保持游戏可玩。不让模型执行任意代码或逐帧直接控制角色身体。

将现有规则任务、探索和存档逐步迁移为 UE 数据与 SaveGame。区分当前已实现能力与未来“玩家上传场景生成世界”愿景。旧浏览器角色为分段模型和程序步态，迁移到蒙皮骨骼动画需要单独完成，不能只改导出格式就称为完成。

安装引擎只用正常官方渠道和用户已有授权；账号登录由用户本人完成。只在必要时要求用户提供缺失信息，继续推进不依赖该信息的建模与工程准备。每次交付明确哪些在 UE 中实测、哪些仅通过源资产检查、哪些未完成。

完成后运行相关检查、保存实际引擎截图、打包 Windows 可执行版本、更新说明与 CHANGELOG、提交推送 `hy-8/starbay-ai-world` 并核对远程。大型工程与可执行包发布新 Release，保留旧版本。不要把未运行的 `.uproject` 或 Blender 预览当作已验证的独立游戏。

若本次还制作宣传视频，先读本地 OpenChatCut 技能并用它剪辑、混音、导出，保留 `.ccproj`。宣传使用真实版本的实机画面；概念图和未来功能明确标注。
