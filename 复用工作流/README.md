# 从场景参考到本地 AI 世界：复用入口

这是一套可直接复制使用的完整提示词与制作说明，不需要安装插件或注册 Skill。

**2026-09-22 更新：后续主线已切换为 UE5 Windows 独立游戏。继续当前项目优先使用 [04：UE5 独立游戏提示词](04_UE5独立游戏完整提示词.md)。01—03 保留为原浏览器版本的制作与复用记录。**

## 下次怎么用

1. 准备场景参考图片，选一个新项目目录。
2. 将 [完整提示词](01_直接复制使用的完整提示词.md) 复制给执行助手，填写开头的项目参数；也可以直接让助手读取该文件并执行。
3. 如果是在当前项目上继续开发，明确写“继续现有项目”，让助手先读取项目 `AGENTS.md`，不要重新生成并覆盖已有模型。
4. 按需要选择游戏、文档、视频、旁白、封面和 GitHub 交付范围。

可直接发给助手：

> 请先阅读本文件所在目录的《01_直接复制使用的完整提示词.md》和《02_本项目流程与文件索引.md》，按完整提示词执行。参考素材目录：【填写】；新项目目录：【填写】；虚构世界名：【填写】；本次交付：【填写】。先核对本地环境和现有文件，保护手工编辑，缺失的非关键参数采用合理默认值。
