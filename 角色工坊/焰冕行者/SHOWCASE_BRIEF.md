# 绯序 · 演唱会角色作品方向

2026-09-29 用户改为红发、酒红长外套、黑色内搭与修身裤靴的写实演唱会造型，减少粒子。随后明确指出初稿粗糙，要求先打磨模型，准备发布角色作品观察反馈。当前优先级是模型和离线作品展示，暂停 UE 接入、新游戏包及这批候选的 Release 发布。

## 当前审核结论

concert01—concert05、rig_concert01、motion_concert01 是保留的试作，**未通过作品质量验收**。问题包括：塑料片式头发、皮肤缺少贴图层次、肩部和翻领接缝、服装过于规则、面部神态与参考差距。不要把文件生成成功、骨架存在或渲染完成写成已经满足用户要求。

## 这轮制作顺序

1. 面部近景：真实的肤色变化、眼睑/嘴唇/鼻翼，自然眼球材质，避免用平涂肤色代替细节。
2. 发型：重做分缕和发际线，层次、体积和散发；离线展示先用真实细发丝，不急于压缩游戏面数。
3. 服装：领口、肩缝、袖窿、袖口、腰线必须连接可信；黑色内搭和酒红外套分清材质，褶皱沿受力方向。
4. 表现：自然站姿或舞台招呼，克制灯光，无魔法火焰。不能用暗光、烟雾或后期掩盖结构错误。
5. 展示：全身、脸部近景、背面、无特效检查图；先看模型是否值得发布，再准备宣传排版。用户尚未授权向社交平台发帖。

新候选全部单独保存。旧焰冕角色、已发布游戏和用户参考图片不覆盖。第三方人体/贴图如有使用，逐项保存来源、许可和哈希。每张角色展示图必须由实际 3D 工程渲染，不能用生成图片冒充建模成果。

## 2026-10-02 · 静态效果图检查稿

用户本轮要求「接着做，先做 3d 效果图」。本轮继续做实际模型，未转成 AI 插画。当前未摆姿势模型为 `Exports/concert14/Ember_Regent.blend`，展示工程为 `Exports/editorial03/Redline_Editorial.blend`；图片在 `Renders/editorial03`，包括全身、半身、脸部近景、背面。源工程、贴图均保留本地；这是制作中检查稿，尚未通过用户作品验收，不创建新的游戏 Release。

- 用 MakeHuman CC0 short02 发片与法线替换旧成束假发，增加原创细曲线散发；恢复眉毛，保留已有真实皮肤 UV 和眼球模型。来源逐项记录于 `Source/showcase_cc0_sources.json`，实际使用清单在 `Exports/concert14/showcase_asset_usage.json`。
- 重建内搭、修复胸口补片缺少肤色属性导致的黑块；饰链拟合胸口，加入衣物细缝与克制的肩部装饰。展示工程剔除完全被外套覆盖的内搭面，避免新视角下的穿插。
- 手臂下垂、头部轻转、一脚稍前移，均为可编辑几何静态造型。**不是新骨骼绑定、动画或布料模拟**，没有同步到 UE 游戏。
- 用真实弧形摄影棚背景替代地平线突兀的平面，输出 Cycles 192 samples 图片。每个输出都保留独立版本，不覆盖旧模型。

诚实的质量判断：这轮解决了部分结构和材质错误，但头发仍有块状感；脸部缺乏参考图的个性和表情；外套的褶皱、袖口、靴形和装饰密度还比较简化。不能称为参考级写实成品，也不建议作为“最终角色”发布。后续优先重新设计中长层次发型、精雕面部、重做服装剪裁和真实褶皱，再做发布排版。

重建顺序（本地已有基础资产时）：

1. Blender 后台运行 `Tools/build_editorial_still.py -- 新模型版本 --draft`。`--draft` 只降低建模检查渲染采样，不降低模型精度。
2. Blender 后台运行 `Tools/render_editorial_pose.py -- 新展示版本 新模型版本`，生成高分辨率图片及工程；不带 `--draft` 为 192 samples。
3. 查看所有角度，保留失败候选；脚本拒绝覆盖已有输出。

GitHub 仅同步制作源码、许可记录和本轮检查图证据。之前未验证的演唱会 UE 脚本及旧 concert05 动画试验继续保持暂停。
