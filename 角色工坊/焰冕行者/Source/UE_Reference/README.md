# Epic animation reference files

Manny.fbx and the six locomotion/jump FBX files were exported from the locally installed Unreal Engine 5.6 template content. Source paths, file sizes and SHA-256 values are recorded in sources.json. They retain Epic Games licensing; they are not CC0. The converted motions retain applicable source restrictions. These references support the Unreal Engine character workflow and do not include the user's inspiration images or another game's extracted models.
