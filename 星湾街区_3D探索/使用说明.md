# 星湾街区使用说明

星湾是虚构的都市游戏世界。所有地点、商场、商家和居民均为游戏设定，不对应真实城市或商业机构。

双击「开始探索.cmd」启动。需要 Python 3.10+ 和支持 WebGL 的浏览器。默认网址为 http://127.0.0.1:8765 。

## 玩法

WASD 移动，鼠标环顾，Shift 快走，Esc 释放鼠标，E 交谈，F 互动，J 查看任务。点击「去商场入口」可步行进门，「逛商场新店」直达服饰、数码和餐饮区。

一天约20分钟，可休息快进到清晨、白天、黄昏或夜晚。12个地点、8类任务、街区币与经验组成当前的探索循环；街区币尚不能购物。新店陈设用于视觉探索。

12位居民有成年男性、成年女性、老人、孩子四类原创都市造型；普通行为能寻路、等灯、避让和带路。休息目前为站立停留，车辆为静态道具。

约每10秒自动保存到当前浏览器本地存储。沿用相同浏览器与端口可以继续进度；本版兼容此前本机原型的存档。

## AI 如何参与

启动 Ollama 并安装 qwen3.5:4b，可用中文与居民对话，例如「请带我去口袋公园，我跟着你」。模型负责语言与目的地选择，服务校验目标后由路径图和动画程序执行。关闭AI仍能探索和做任务。任务、奖励、昼夜和存档由规则程序实现。

模型只接收本机角色状态与聊天文字，连接127.0.0.1:11434；无需云端API密钥。环境变量 STARBAY_AI_MODEL 可选择已安装的其他模型。

## 编辑与重建

Blender 4.5 LTS 可以打开「星湾街区.blend」与 assets/npc_*.blend。先运行 build_people_v4.py，再运行 build_scene.py；可以传入 -- --skip-preview 跳过静态预览。生成会覆盖对应输出，请先保护手工修改的工程。

前端：app.js、game.js、game-ui.js、navigation.js、people.js、daylight.js；本地服务：server.py；模型生成：build_scene.py、build_world_v3.py、build_interior_v4.py、build_people_v4.py。
